## Description

BuildCheck is an evidence-first product validation workspace for founders and AI agents. Seven native WebMCP tools let an agent challenge an idea, inspect structured evidence, estimate build scope, propose the smallest validation MVP, and apply a pre-build guard — while the human keeps the final decision.

Live demo: https://buildcheck-webmcp.vercel.app
Agent workspace: https://buildcheck-webmcp.vercel.app/agents
Source code: https://github.com/madouyatt95/buildcheck-webmcp
